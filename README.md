# Sistem Deteksi Tren dan Analisis Evolusi Topik Berita

**Status Proyek:** In Development

## Deskripsi

Proyek Capstone Teknik Informatika ini bertujuan membangun sistem deteksi tren dan analisis evolusi topik berita berbahasa Indonesia menggunakan pendekatan Big Data dan Natural Language Processing (NLP).

Sistem direncanakan untuk mengolah data berita, mengelompokkan artikel berdasarkan topik, menganalisis perubahan aktivitas pemberitaan dari waktu ke waktu, serta menyajikan hasil analisis melalui dashboard web.

## Tujuan

- Mengolah dataset berita berbahasa Indonesia.
- Mengelompokkan artikel berdasarkan kesamaan topik.
- Menganalisis perkembangan topik berdasarkan waktu.
- Mendeteksi peningkatan aktivitas pemberitaan.
- Menampilkan hasil analisis dan sumber berita melalui dashboard.

Teknologi final akan ditentukan berdasarkan kebutuhan sistem, ketersediaan dataset, dan hasil pengujian.
